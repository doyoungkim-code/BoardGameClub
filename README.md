# Do you 보드게임?

보드게임 동호회 회원들을 위한 전용 웹앱입니다.
여러 모임이 함께 쓰는 서비스가 아니라 **한 동호회만을 위한 내부 공간**이며, 회원의 소개로 가입 신청을 하고 운영자가 승인하면 이용할 수 있습니다.

## 할 수 있는 것

- **가입·회원 관리:** 구글 계정 로그인, 운영자 승인제 가입, "OO의 지인" 소개 관계 표시
- **채팅:** 채널별 단체 대화방과 회원 간 1:1 메시지
- **모임:** 정기모임과 번개 일정, 참석 신청, 출석 체크
- **보드게임 기록:** 동호회 보유 게임 목록, 플레이 기록과 승패·점수 통계
- **게시판:** 공지사항, 자유게시판, 게임 후기

휴대폰 화면을 기준으로 만들었고 PC 브라우저에서도 사용할 수 있습니다.

## 만든 기술

React · TypeScript · Tailwind CSS · Firebase
